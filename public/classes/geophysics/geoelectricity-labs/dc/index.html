전기탐사: 물성, 관측, 해석의 구분

모형의 예측을 관측값과 비교하고, 서로 다른 지하 조건이 구별되는지 확인합니다.

1. 물성의 비유일성2. SP 측정과 기준점3. DC 관측과 모델 탐색4. IP 감쇠와 측정 시간창

1. 같은 비저항을 만드는 서로 다른 물성

공극률, 포화도, 공극수 비저항을 바꾸어 시료의 비저항과 측정 전압을 비교합니다. 점토가 있는 시료에 깨끗한 모래의 관계식을 적용할 때 생기는 오차도 확인합니다.

예측 비저항이 낮아졌다면 수분이 증가했다고 결론 내릴 수 있습니까? 먼저 물성을 고정하고 시료의 길이만 두 배로 바꾸십시오.

시료 조건

수업 과제와 확인
  1. 시료 길이를 0.5 m에서 1 m로 바꾸고 전압·저항·비저항 중 무엇이 달라지는지 기록합니다.
  2. “같은 비저항의 두 시료”를 누릅니다. 두 시료가 서로 다른 포화도를 갖지만 같은 비저항을 갖는 이유를 계산합니다.
  3. 표면전도도를 0에서 0.01 S/m로 올립니다. 이를 무시한 Archie 역산이 어떤 포화도를 주는지 확인합니다.

비저항 하나만으로 공극률·포화도·염분·표면전도를 각각 결정할 수 없습니다. 공극수 전기전도도, 시료 분석, 지질 정보를 함께 확보해야 합니다.

계산식, 가정 및 English explanation
σpore = φmSwn / (aρw)
σbulk = σpore + σsurface, ρbulk = 1/σbulk
R = ρbulkL/A, ΔV = IR

a = 1, m = n = 2를 고정합니다. 시료는 균질하고 등방성이며 완전한 단면 전극을 가정합니다. 표면전도 항은 독립적인 병렬 경로를 나타내는 교육용 근사이며, 실제 점토의 포화도·염분 의존성을 재현하지 않습니다. 접촉저항과 전극 분극은 제외합니다. 지표의 4전극 탐사에는 시료식 R = ρL/A를 적용하지 않습니다.

Bulk resistivity does not uniquely determine water saturation. Pore-water resistivity, porosity, saturation, and surface conduction can compensate one another. Length and cross-sectional area change the measured resistance but not the intrinsic resistivity. The constant parallel surface-conduction term is an illustrative approximation, not a complete petrophysical model for clay.

참고: GPG: DC Resistivity, EPA: Electrical Methods. 계산값은 합성자료이며 실제 시료 측정값이 아닙니다.

2. SP 이상과 측정 오차의 구분

동일한 지하 전류쌍극자의 표면 전위를 고정 기준점 방식과 이동 전극쌍 방식으로 관측합니다. 기준점 재측정과 폐합오차 보정이 각각 무엇을 해결하는지 비교합니다.

예측 각 측정에 같은 1 mV 전극 오프셋이 더해질 때, 두 방식의 최종 전위 단면은 어떻게 달라집니까?

지하 전류원과 전극 오차

수업 과제와 확인
  1. 시간 드리프트를 0으로 하고 일정 오프셋을 1 mV로 설정합니다. 이동 전극쌍의 누적값에 생기는 기울기를 확인합니다.
  2. 드리프트를 0.15 mV/측정으로 바꾸고 폐합 보정 후의 곡선도 참값과 다른지 확인합니다.
  3. “깊이·모멘트 교환”을 누릅니다. 깊이와 모멘트를 각각 두 배, 네 배로 늘렸을 때 기준점 전위를 빼기 전 중심 전위가 같아도 단면 폭이 달라짐을 설명합니다.

폐합오차 하나는 모든 시간 변화를 결정하지 못합니다. 이 예에서 일정한 전극 오프셋은 균등 폐합 보정으로 제거되지만 시간에 따라 바뀌는 오프셋은 잔류 곡률을 만듭니다. 고정 기준점 자료는 시작·종료 기준점 관측으로 선형 드리프트를 정확히 제거할 수 있습니다.

계산식, 가정 및 English explanation
V(x) = M[(x − x₀) sin θ + h cos θ] / [(x − x₀)² + h²]3/2
Vfixed,i = V(xᵢ) − V(x₀,ref) + b + di
δVgradient,i = V(xᵢ) − V(xᵢ₋₁) + b + di

h는 양의 깊이(m), θ는 수직에서 기울어진 각도, M은 전도도와 전류쌍극자 모멘트를 포함한 크기(mV·m²)입니다. 이 페이지에서 전류원의 x 좌표는 0, 기준 전극은 −50 m입니다. b는 두 전극 사이의 일정 오프셋, d는 한 측정 시간 간격에 증가하는 오프셋입니다. 마지막 폐합 관측은 한 번에 기준점으로 돌아간 것으로 처리합니다. 오차를 경로 길이에 비례해 배분한 것이 아니라, 측정 횟수에 비례해 배분합니다. 임의 잡음과 횡방향 비저항 변화는 제외합니다.

An equivalent current dipole in a homogeneous half-space generates the synthetic SP profile. This model does not uniquely specify groundwater flow, an orebody, or a redox source. A constant electrode offset accumulates in a leapfrog survey. Linear loop-closure correction removes this constant offset in the present equal-time acquisition, but a time-dependent offset leaves residual curvature. Repeated base measurements constrain instrument drift.

참고: EPA: Self-Potential. 음·양의 SP 이상만으로 유동 방향이나 누수 위치를 일반적으로 결정할 수 없습니다.

3. 전극 간격, 겉보기비저항, 모델의 비유일성

수평 2층 구조에서 전압을 계산하여 겉보기비저항으로 바꿉니다. 관측에 사용한 최대 간격이 충분하지 않으면 여러 하부층 비저항·경계 깊이 조합이 자료를 설명할 수 있습니다.

예측 최대 전극 간격이 얕은 층 두께보다 작으면, 하부층의 비저항을 어느 정도 제약할 수 있습니까? 모델을 먼저 예상하고 탐색하십시오.

합성 관측과 비교 모델

수업 과제와 확인
  1. “짧은 측선”을 선택하고 모델 탐색을 실행합니다. 허용되는 경계 깊이와 하부층 비저항 범위를 확인합니다.
  2. “긴 측선 (100 m)”을 선택하고 다시 탐색합니다. 관측 간격 범위를 확대하면 어느 방향의 모호성이 줄어드는지 기록합니다.
  3. 배열과 현재 간격을 바꿔 ΔV와 K를 비교합니다. 동일한 균질 매질에서 배열을 바꾸어도 ρₐ가 같은지 “균질 매질”로 확인합니다.
  4. 현재 간격을 늘리면서 전압과 상대적인 감도 변화를 구분합니다. 큰 간격은 반드시 높은 신호 대 잡음비를 보장하지 않습니다.

여기서 확인하는 것은 유한한 관측 간격과 잡음에 따른 2층 모델의 비유일성입니다. 얇은 중간층의 종전도도·횡저항으로 설명하는 3층 등가성은 이 계산에 포함되지 않습니다.

계산식, 가정 및 English explanation
k = (ρ₂ − ρ₁)/(ρ₂ + ρ₁)
G(r) = 1/r + 2 Σn=1…∞ kⁿ / √[r² + (2nh)²]
ΔV = ρ₁I/(2π) [G(AM) − G(BM) − G(AN) + G(BN)]
D = 1/AM − 1/BM − 1/AN + 1/BN, K = 2π/D, ρₐ = KΔV/I
RMS = √{ mean[ ((ρₐ,pred − ρₐ,obs)/sᵢ)² ] }

ρ₁ = 100 Ω m를 독립적인 얕은 자료로 안다고 가정합니다. 영상전하 급수는 |kⁿ| < 10⁻¹²에서 종료하며 최대 2,000항을 사용합니다. 현재 범위 ρ₂ = 10–1,000 Ω m에서는 수렴합니다. 각 측정의 표준편차 sᵢ는 참 응답 × 설정한 상대 잡음입니다. 고정된 난수열을 사용하여 재현 가능합니다. RMS ≤ 1은 알려진 표준편차와 비교하는 교육용 기준이며 신뢰구간이 아닙니다. 가장 작은 RMS가 유일한 정답을 의미하지 않습니다.

Wenner: A–M–N–B 등간격 a, K = 2πa. Schlumberger: AB/2 = a, MN = 1 m. Dipole–dipole: AB = MN = a, B–M = 3a. 후자의 전극 부호 정의에서는 ΔV와 K가 모두 음수일 수 있고 ρₐ는 양수입니다. 전류는 A에 주입하고 B에서 회수하며 전압은 V(M) − V(N)입니다.

The surface potential of a point source above a horizontal two-layer earth is calculated with the convergent image series. Apparent resistivity is the homogeneous-half-space resistivity that reproduces the measured voltage for the selected array. It is not a local average at a fixed depth. The model search holds the upper-layer resistivity fixed and explores lower-layer resistivity and interface depth. The accepted region illustrates finite-data ambiguity, not a posterior probability distribution or a full 2D ERT inversion.

참고: GPG: DC Resistivity, EPA: Resistivity Methods.

4. 같은 충전율과 서로 다른 감쇠

전류 차단 뒤의 감쇠를 두 개의 완화시간으로 표현합니다. 측정 시작 지연과 적분 시간창을 바꾸어 관측하지 못한 분극과 실제 보고되는 충전율을 구분합니다.

예측 빠른 감쇠 성분이 강한 시료를 늦게 측정하면, 분극이 약한 시료로 판단할 수 있습니까? 같은 충전율을 주는 두 감쇠곡선은 다른 시간창에서도 같습니까?

분극과 측정 조건

정의단위시간창 변경의 영향
∫V(t)dt / Vₚs 또는 ms시간창 길이와 감쇠 모두에 의존
∫V(t)dt / [Vₚ(t₂ − t₁)]V/V 또는 mV/V시간창의 평균 잔류전압에 의존
수업 과제와 확인
  1. 초기 감쇠가 큰 조건에서 측정 지연을 1 ms에서 100 ms로 늘립니다. t = 0 직후 분극 중 몇 %가 첫 관측 전에 소멸하는지 확인합니다.
  2. “같은 시간창 충전율의 모형”을 누릅니다. 두 감쇠곡선의 모양이 달라도 적분값은 같음을 확인합니다.
  3. 비교 모형을 고정한 채 시간창 끝을 500 ms에서 1,000 ms로 바꿉니다. 동일했던 두 충전율이 계속 같은지 확인합니다.
  4. 통전 시간을 4 s에서 0.1 s로 줄입니다. 긴 완화시간 성분이 충분히 충전되지 않는 이유를 설명합니다.

충전율은 사용한 시간창과 통전 이력을 함께 보고해야 합니다. 서로 다른 장비·시간창의 수치를 직접 비교하면 분극 차이와 측정 조건 차이가 섞입니다. 여러 시간창이나 주파수에서의 관측이 감쇠의 형태를 추가로 제약합니다.

계산식, 가정 및 English explanation
D = 1 − Σ mⱼ exp(−Ton/τⱼ), Vₚ = V∞D
V(t)/Vₚ = Σ mⱼ [1 − exp(−Ton/τⱼ)] exp(−t/τⱼ) / D
Mint = Σ mⱼ [1 − exp(−Ton/τⱼ)] τⱼ [exp(−t₁/τⱼ) − exp(−t₂/τⱼ)] / D
Mavg = Mint/(t₂ − t₁)

충분히 오래 통전한 기준 전압 V∞ = 100 mV를 고정하고, 독립적인 Debye형 성분 두 개를 선형 합합니다. mⱼ는 충분히 오래 통전했을 때의 정규화된 감쇠 진폭이며, 시간창 충전율 자체가 아닙니다. 0부터 일정 전류를 통전하고 그 전에 완전히 이완되었다고 가정합니다. 유한 통전에서 실제 차단 직전 전압 Vₚ도 달라지므로 위의 D로 정규화합니다. 여기서는 분극의 시간 응답만 모델링하고, 불균질 지하의 공간 감도, 전자기 결합, 전극 분극, 잡음은 제외합니다. 성분 1과 2의 완화시간은 독립적으로 설정하므로 어느 성분이 더 빠른지는 현재 τ값으로 판단합니다. 같은 τ가 동일한 광물이나 입자 크기를 유일하게 뜻하지 않습니다.

Two independent exponential relaxation components describe the synthetic voltage decay. Finite charging time reduces the amplitude of slow components and changes the primary voltage immediately before switch-off. All normalized decays and chargeabilities use that actual primary voltage. Integrated chargeability has units of time, whereas the time-averaged normalized voltage is dimensionless and is often reported in mV/V. A single gate cannot determine the relaxation spectrum. The alternative model matches one gate only; changing the gate can distinguish the two responses.

참고: GPG: Induced Polarization, EPA: Induced Polarization의 충전율 정의. 지수 감쇠는 교육용 완화모형입니다.
