Geometry sculpting and numerical calculation

Surface points within the brush radius are deformed with distance weighting for pulling, inflation, deflation, and smoothing. Selected boundary points and cross-sections can be added or deleted. Cross-sections with different point counts are periodically resampled before voxelization. After editing, rebuild the voxels to evaluate the vertical gravity component of each rectangular prism analytically.

Terrain data and scope

When terrain is enabled, AWS Open Data Terrain Tiles are loaded and gravity is calculated at the terrain elevation of each observation-grid point. Source data and effective spatial resolution vary by region. The calculation represents a homogeneous density-contrast body in a local WGS84 tangent plane; it does not include the reference gravity field or corrections applied to observed gravity data.

Gravity calculations are performed in the browser. Terrain Tiles for the specified region are downloaded from AWS Open Data only when terrain loading is requested. Terrain: Mapzen · AWS Open Data.
